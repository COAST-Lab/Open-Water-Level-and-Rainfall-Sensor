# Open Water Level and Rainfall Sensor
## ℹ️ About this Repository
This repository provides information on firmware, fabrication, data analysis, and educational resources for the novel open water level and rainfall sensor (OWLR)! 

## 🔌 Introduction to the Sensor
This sensor utilizes the XL-MaxSonar-WRLA1 MB7076 Waterproof Ultrasonic Distance Sensor and DFRobot Tipping Bucket Rainfall Sensor sensors alongside Particle Boron for a novel, low-cost (Under $400 US) water level and rainfall sensor that utilizes cellular and solar power!

## 🌟 Goals 
    - Sensor Design: Have a well validated and easy to build open source low cost water level and rainfall sensor
    - Education: Formulate lesson plans that utlize experiential and place-based learning. Engage students through the creation and deployment of their own sensor.
